# Inteligência Artificial — exercícios e experimentos

Repositório acadêmico de Ciência da Computação com algoritmos de busca e otimização, implementações e relatórios.

## Organização
| Diretório | Tema |
| --- | --- |
| [`ed02-codigo`](ed02-codigo) | Busca em espaço de estados: BFS, DFS, gulosa e A* |
| [`ed02-relatorio`](ed02-relatorio) | Relatório de algoritmos de busca |
| [`ED03-codigo`](ED03-codigo) | Algoritmos genéticos aplicados ao problema da mochila |
| [`ED03-relatorio`](ED03-relatorio) | Análise e relatório de otimização |
| [`ED04`](ED04) | Material adicional da disciplina |

## Conceitos
- Comparação entre busca informada e não informada.
- Heurísticas de peças fora do lugar e distância de Manhattan.
- Algoritmos genéticos para otimização com limite de capacidade.
- Análise dos resultados por meio de Python e bibliotecas científicas.

## Reproduzir
Cada exercício tem requisitos próprios. Consulte o código e os relatórios das pastas antes de executar; não existe um comando único para todo o repositório.

## Documentação a complementar
Comandos e dependências de cada exercício, parâmetros dos experimentos e exemplos de resultados.
